# 중학교 정보 코스웨어 (2022 개정 교육과정)

NCIC 국가교육과정 정보센터의 **2022 개정 교육과정 중학교 정보과 성취기준**을 바탕으로 한 실시간 수업 웹앱입니다.

## 주요 기능

- 교사: 임의 비밀번호로 수업 생성 / 학생 실시간 위치·손들기·제출 모니터링 / 집중시키기(화면 공유·이동 잠금)
- 학생: 수업 코드·이름·성별 입력 → 랜덤 아바타 → 우측 현황(위치·형성평가 점수)
- 5개 대단원 수업: **도입 → 전개 → 정리** + 유튜브 연계 영상 + 형성평가(주관식·서술형)
- 단원 특화
  1. 컴퓨팅 시스템: 3D PC 부품 탐구
  2. 데이터: 진법 변환·디지털 표현 실습
  3. 알고리즘과 프로그래밍: 랜덤 문제 AI 피드백 + 브라우저 파이썬(Pyodide) + AI 채점
  4. 인공지능: 데이터 입력 후 분류 모델 체험
  5. 디지털 문화: 과거·현재·미래 활동, 개인정보, 저작권·CCL
- 교사 AI 연동: GPT / Gemini / Claude API 키로 서술형·알고리즘·코드 피드백

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속

1. 교사 탭에서 비밀번호 생성 후 **새 수업 만들기**
2. 화면에 표시된 **수업 코드**를 학생에게 안내
3. 수업 로비에서 AI Provider와 API Key 저장
4. 학생은 코드·이름·성별 선택 후 입장

## 기술 스택

- Next.js 15 (App Router) + TypeScript + Tailwind CSS 4
- Socket.IO 실시간 교실
- React Three Fiber (3D PC)
- Pyodide (브라우저 파이썬)
- Zustand (세션)
